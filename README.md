# 家装全流程参谋

菜单式交互装修手册 —— 覆盖新房 / 旧房改造，从拆改到入住全流程。定位「客户这边的装修避坑参谋」，利他、不站厂家。

## 文件清单
- `家装全流程参谋.html` — 交互版：阶段菜单切换、全局搜索、27 张参数 SVG 图（插座高度 / 坑距 / 衣柜橱柜尺寸 / 电器预留等）、8 大装修风格库、全屋智能布线点位。
- `家装全流程参谋.pdf` — 打印 / 离线版，微信里当文件发可直接打开（38 页，含全部阶段、参数图与风格库）。

## 本地预览
直接用浏览器打开 `家装全流程参谋.html` 即可，无需联网、无需服务器，单文件离线可用。

## 微信分发说明
- `*.app.workbuddy.host` 会按 UA 拦掉微信内置浏览器（客户扫码直接撞「请在浏览器中打开」），不可用。
- 本仓库 GitHub Pages（`https://<用户名>.github.io/<仓库名>/`）微信内可正常打开，适合做扫码入口。
- 推广素材 `推广海报.png` / `家装参谋-二维码.png` 需把二维码指向本仓库 Pages 地址后重新生成。

## 部署（GitHub Pages）
1. 仓库 Settings → Pages → Source 选 `main` 分支、`/root`（已带 `.nojekyll`）。
2. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

## 设计规范
- 主题色：藏蓝 + 橙（侯哥品牌色）。
- 智能方案严格采用「零火版智能开关 + 无线场景开关」，不含单火 / 凌动。
- 不报价，CTA 统一落「私信免费户型诊断」。
